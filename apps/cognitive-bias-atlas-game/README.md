# Cognitive Bias Atlas Game

## Problem

Cognitive biases are often taught as lists. This prototype explores whether bias education can become spatial, playful, and memorable through discovery, collection, and interactive feedback.

## Users

- Learners
- Educators
- Training designers
- Interactive media reviewers
- Game/prototype evaluators

## Key Features

- Three.js 3D world prototype
- Open atlas exploration
- Procedural terrain chunks
- Close shoulder hybrid camera
- Collision detection for crystals, obstacles, ridges, and structures
- Bias crystals with washing/collection mechanic
- Parkour-style biome obstacles
- Rare mushroom scout mode
- Basic build structures using collected bias points

## Technology Notes

- Single-file Three.js prototype
- Static web deployment
- Procedural generation and lightweight collision approximations
- Designed for rapid gameplay exploration rather than production game architecture
