# Creative & Brand Portfolio

Selected design work by Robert Franc-Klein. A static, responsive subsite with six project pages, category filters, an accessible keyboard-operated image viewer, publication/artwork PDFs and a creative project management resume.

## Content
- Futures: brand strategy and launch collateral.
- WANDER: editorial design proof and selected layouts.
- Circadia: brand application exploration, clearly distinguished from commissioned work.
- Identity studies: concepts from the design archive, not a claimed client list.
- All Things Pretty: brand portraiture.
- Makers & spaces: environmental photography collection.

Stock asset libraries, raw camera archives, marketplace templates, the source Circadia brand guide, market research documents and unedited project files are not published. Web images are resized copies with camera metadata removed. The source archive is unchanged. The included asset manifest records source filenames and presentation context.

## Run
Serve this directory with any static HTTP server. No build or package installation is required. Google Fonts are optional; system font fallbacks are supplied. The core portfolio remains usable without JavaScript; JavaScript adds filtering and the image viewer.

## Deployment
Live under the existing portfolio at `https://storage.googleapis.com/raf-business-app-portfolio-757561763135/creative/index.html`. All page links are relative. The parent portfolio links to this subsite.
